# CellScope — 細胞計数盤カウンター（ブラウザGUI）

Jupyter Notebookを使わない、**ローカルで動くWebアプリケーション**です。
画像はクラウドに送らず、起動したPCの中で処理します。インターネットは初回のPythonライブラリ導入時だけ必要です。

## 起動方法

### Windows 10/11（uvを使った起動）

Windowsでは `run_windows.bat` を使います。**Pythonを事前にインストールする必要はありません**が、`uv` のインストールが必要です。

1. PowerShellでuvをインストールします（[公式インストール手順](https://docs.astral.sh/uv/getting-started/installation/)）。
   ```powershell
   irm https://astral.sh/uv/install.ps1 | iex
   ```
2. PowerShellを開き直して、`uv --version` でインストールを確認します。
3. リポジトリをZIPで取得して展開するか、cloneします。
4. **`run_windows.bat`** をダブルクリックして起動します。
5. 初回はuvがPython 3.13の仮想環境 `.venv` を作成し、必要なライブラリをインストールします。ブラウザでCellScopeを操作します。
6. 終了はコマンドプロンプトで **Ctrl+C** を押します。

初回のPython・ライブラリのダウンロードにはインターネット接続が必要です。uvが見つからないなどのエラーが出るときは、コマンドプロンプトで `run_windows.bat` を実行するとメッセージを確認できます。

**別の方法（Pythonがインストール済みの場合）**

```powershell
py -3 -m pip install -r requirements.txt
py -3 app.py
```

このアプリは単一HTMLだけではなく、ローカルのPythonで画像処理します。

### macOS

1. ZIPを展開し、ターミナルでそのフォルダへ移動して `bash run_mac.command` を実行します。
2. 初回は必要なライブラリを自動インストールし、ブラウザにアプリが開きます。
3. 終了するときは、ターミナルで **Control+C** を押します。

macOSのセキュリティ設定によって `.command` ファイルをダブルクリックで開けない場合があります。その場合は上の方法を使ってください。

### 共通・手動起動

```bash
python -m pip install -r requirements.txt
python app.py
```

必要なもの：Python、NumPy、OpenCV。**Jupyter / Streamlit / Flask不要**。

## 使い方

1. TIFF画像（PNG / JPGも可）を、まとめて右側のアップロード欄に読み込みます。
2. A、B、C、Dの各区画に画像を割り当てます。同じ画像を4区画で使うことも可能です。
3. 画像の向きが違う場合は「太い格子線の位置」で赤枠にする2辺を変更できます（既定値は説明書のA〜Dに従います）。
4. ［範囲指定］を選び、1 mm × 1 mmの計数区画を**細／太の格子線の中心**を角にしてドラッグで囲みます。
5. ［この区画を自動検出］で検出点を表示します。初期設定の「紫・青色に染色した細胞」は青紫に染まったミドリムシ用です。
6. 拡大して、［追加］［削除］［採否］［個数＋］［個数−］で目視修正します。青い点は手動追加、緑色は採用、赤は除外です。重なった細胞には個数が表示されます。
7. 細胞が細い境界線に触れる場合は採用、太い境界線に触れる場合は除外します。枠線は水色＝細線、赤＝太線です。境界での自動処理は近似なので、最終判断は手動確認してください。
8. 区画ごとに［この区画を目視確認した］にチェックを付けます。
9. 希釈倍率を指定し、［結果を保存］で **集計CSV、細胞座標CSV、注釈画像、計算結果JSON、再開用session.json** をZIPで保存します。

### 過去の計数結果について

個別の実験画像に対応する `previous_data.json` は研究データを含むため、GitHub配布版から除外しています。
アプリはこのファイルがなくても正常に起動・自動検出できます。手元に `previous_data.json` がある場合のみ、`app.py` と同じ場所に置くと、元画像のハッシュが一致するデータを復元できます。
作業中に保存した `session.json` は、元画像と合わせてGUIから再読み込みできます。

### 作業の再開

上部の［作業を再開］は `session.json` を読み込みます。**元画像はJSONに入っていません**ので、再起動したらまず元のTIFF画像を読み込んでからJSONを読み込んでください。

## 計算式

取扱説明書の各区画は 1 mm × 1 mm × 0.1 mm = 10⁻⁴ mL です。

\[
C = \frac{N_A + N_B + N_C + N_D}{4}\times 10^4\times D
\]

`D`は希釈倍率、`C`は cells/mL。4区画のROIと画像がすべて設定されたときのみ濃度を表示します。

## 注意事項

- **画像から自動抽出した点は候補**です。細胞密度は、4区画の目視検証後に採用してください。
- 重なった細胞、弱い染色、気泡、ゴミ、境界線に接した細胞は計数誤差が出ます。
- 各区画のROIは**ちょうど1 mm 四方の計数室全体**を選んでください。違う格子（細かい格子）を選ぶと換算式が成立しません。
- 太線／細線の規則はA=右下、B=左下、C=左上、D=右上を太線として実装しています。実際の計数盤の向きと一致しているか確認してください。
- 画像はアプリ内で一時保持されます。アプリ終了時に画像・点は消えるため、ZIPまたはJSONを書き出してください。
- このアプリは研究用途の試作版で、医療診断用ではありません。
